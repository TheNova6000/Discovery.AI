01 // about

An investigation graph, not a knowledge base

Most tools that answer questions give you a paragraph and hide the work. Discovery.Ai does the opposite: every question gets recursively broken into sub-questions, each one investigated on its own, and the whole process is rendered as a graph you can navigate.

Zoom into any node to see what's actually known about it. Go deeper to trigger a fresh investigation. Switch lenses — economic, technical, historical — and watch the same entity get re-explored through a different frame entirely.

It's deliberately honest about what it is: a trace of how the system explored a subject, not a claim that the subject is now fully modeled. The graph grows exactly as far as you push it.

02 // capabilities

What the system actually does

[ 01 ]

Recursive investigation

Every question decomposes into sub-questions, answered independently and synthesized back up — not a single flat LLM call.

[ 02 ]

Live graph playground

Watch the graph build in real time. Focus, siblings, and parents are all visually distinct — you always know what you're looking at.

[ 03 ]

Switchable lenses

Re-investigate the same entity through an economic, technical, or any other named dimension — the system re-frames, not just re-reads.

[ 04 ]

Session history

Every conversation is kept, switchable from the side rail — nothing is silently overwritten when you start something new.

[ 05 ]

Google sign-in

Your investigations are yours — sign in with Google and every graph and session is scoped privately to your account.

[ 06 ]

Honest provenance

Ask "why is this here" on any entity and see exactly which question surfaced it — the graph never hides its own reasoning.
