BEFORE YOU START

Every investigation here runs on a real LLM call, not a script. This account can run on a free shared pool to start — no setup needed — but that pool is shared by everyone using this app right now, so it can run dry at busy times and your questions will fail with a quota error that has nothing to do with what you asked.

Add your own free API key from any of these providers and your investigations run on your own quota instead — never blocked by anyone else:

  • Groq — free, no card required
  • Google AI Studio (Gemini) — free, no card required
  • Cerebras Cloud — free tier available

Takes about two minutes. Paste whichever ones you get into Settings — you only need one to be covered.
